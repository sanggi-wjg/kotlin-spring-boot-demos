# Part 8. 종합

> 모듈: docs
>
> 지금까지의 실험 결과를 "판단"과 "적용"에 쓸 수 있는 형태로 정리한다. 이 Part에서 만드는 문서가 로드맵 전체의 결과물이다.

---

## 8-1. 판단 가이드 완성 `핵심`

**과제**
- [DECISION-GUIDE.md](./DECISION-GUIDE.md)에 쌓아온 규칙을 **결정 트리** 형태로 다시 정리한다.
  - 예: "외부 호출이 있는가? → 병렬 호출이 필요한가? → 클라이언트가 논블로킹인가? → ..."
- 규칙마다 근거가 된 실험의 장 번호를 단다.

**완료 조건**
- [ ] 근거 링크가 달린 결정 트리
- [ ] 규칙끼리 충돌하는 곳이 없는지 Claude 리뷰

---

## 8-2. 안티패턴 체크리스트 `핵심`

**과제**
- 코드 리뷰에서 바로 쓸 수 있는 체크리스트를 만든다.
  - 형식: "이런 코드가 보이면 → 이런 문제가 생긴다 → 이렇게 고친다"
- 항목마다 재현 테스트(4-4 등)를 연결한다.

**완료 조건**
- [ ] 항목 15개 이상. 항목마다 재현 테스트 링크

---

## 8-3. 회고: 틀렸던 예측들 `핵심`

**과제**
- 모든 장의 "예측과 다른 점"을 모은다.
- 틀린 예측들의 공통점을 찾는다. 내 멘탈 모델의 어느 부분이 틀려 있었는지 정리하는 작업이다.

**완료 조건**
- [ ] 틀린 예측 목록과 그 원인 분류

---

## 8-4. 실제 프로젝트 적용 계획 `선택`

**과제**
- 실무 서비스나 이 레포의 다른 프로젝트(예: `boiler`) 중 하나를 고른다.
- 판단 가이드를 기준으로 코루틴을 도입할지, 어디까지 도입할지 정하는 설계 문서를 쓴다.

**완료 조건**
- [ ] 도입 범위, 도입하지 않을 범위, 그 근거, 위험 요소, 관측 계획
