## 장의 구성

모든 장은 같은 순서로 되어 있다.

1. **이 장에서 답할 질문**: 읽는 목적이다. 장을 마치면 이 질문에 답할 수 있어야 한다.
2. **개념**: 왜 필요한지, 어떻게 동작하는지. 스레드 관점에서 무슨 일이 일어나는지를 중심으로 설명한다.
3. **예제**: 바로 실행할 수 있는 짧은 코드와 예상 출력.
4. **❌/✅ 함정**: 자주 하는 실수와 올바른 방법.
5. **바꿔보기**: 예제를 조금 바꿔 실행하는 과제. 실행 전에 결과를 한 줄로 예상해본다.
6. **정리**: 핵심 3줄, 실무 연결, 이어지는 2단계 장.

## 진행 방법

1. 개념을 읽고 예제를 `basics` 모듈에 **직접 옮겨 치며** 실행한다. 복사해서 붙여 넣기보다 손으로 치는 편이 오래 남는다.
   - 패키지는 예제마다 하나씩 `...basics.guide.<장>.<예제>` 형식을 권장한다. 예: `com.raynor.demo.aboutcoroutine.basics.guide.b4.ex2`. 여러 예제가 같은 이름의 최상위 함수나 변수(`log`, `dbDispatcher` 등)를 쓰므로, 한 패키지에 모으면 이름이 겹쳐 컴파일이 깨진다.
   - 테스트 예제(B-7 등)는 `basics/src/test/kotlin` 아래에 둔다.
   - Spring 예제(D-1)는 `mvc` 모듈에 둔다.
2. 바꿔보기 과제를 한다. 결과가 예상과 다르면 그 이유를 한 줄로 적는다.
3. 이해가 안 되는 부분은 Claude에게 질문한다. 1단계에서는 개념 설명과 예제 코드를 Claude가 바로 알려준다.
4. 장을 마치면 목차의 진행 칸을 체크한다.

기록은 선택이다. 남기고 싶으면 `docs/study/`에 자유롭게 정리한다.
